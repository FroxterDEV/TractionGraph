# TractionGraph
A Java program made for turning CSV tables into a detailed linechart.

# IMPORTANT!!
You **MUST** have Java 8 or above installed to run the program, otherwise it will not work...

## Instrucions
1. Press the folder button to choose a CSV Formatted table (It be formatted like the provided sample tables on this repository)
2. Once the chart is shown you can press the image saving button to save your chart as PNG (IDK why, but it has a bug that lowers the image quality and I dont know how to fix it.. d3b")
